# MyPantry
### Use statement
the original conception of this app was similar to a website I used as a broke college kid that would tell you what you could make based on what food you had in your pantry/fridge. the idea was for a user to be able to write a basic recipe, but add a range of variants. mac'n'cheese is just pasta, bechamel, and cheese, but from that base, you can make chilli mac, bbq pork mac, lobster mac, broccoli-cheddar mac, etc.

from there, a user could add ingredients to their pantry, and if they had everything they needed for a recipe, they would be notified. if they only had enough for the base, but not any variants, they could make their own!

unfortunately, due to time constraints, the pantry portion of MyPantry had to be abandoned, but the recipes and variants are all still functional and accessible to any who visit
